# guides — Recipes and the sorting guide

Draft. The seam below is what a reader may rely on. The pages themselves are written with the piece that needs them. Piece 1 starts the set-up recipes and the sorting guide. Later pieces add a recipe when they add a way in.

One job: words a person or an agent can follow. The screens of the first-run walk belong to app. These pages are the recipes.

## What it owns

The set-up walk in words, one recipe per agent, and the sorting guide agents follow. The guide follows the sorting seam. It does not add a rule.

## What it never does

It holds no sign-in, no mail, no matter and no decision. It is not called as an operation. It never tells Diligent to start an agent.

## Operations

None. A person or an agent reads a page. Nothing here changes the install.

## Hard rules

1. A recipe stays inside the operations the seams name. It does not invent a step those seams forbid.
2. The sorting guide uses `full` and `reference` as sorting defines them. Both levels are part of the seam. Use starts at `full`.
3. A recipe contains no real mailbox, no token and no customer data.

## Inputs

- Working: None yet.
- Reference: [Sorting](../modules/sorting/CONTEXT.md)

## Process

1. Write a recipe so a person can follow it without reading the code.
2. When a seam changes, change the recipe in the same change.

## Outputs

- Set-up recipes
- Sorting guide

## Check

When a recipe is written, a contributor follows it against the seam it names and finds no step the seam forbids.
